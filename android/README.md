# Android module

The Android application will be scaffolded in milestone 6 with Kotlin, Jetpack Compose, Material 3, Hilt, Retrofit, Room, and DataStore.

Local API addresses:

- Android Emulator: `http://10.0.2.2:8000`
- Physical device: configure the development machine's LAN address

No provider API or LLM secret may be stored in this module.
