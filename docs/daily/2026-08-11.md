- 금지 키워드는 코드 상수가 아니라 Git 추적 YAML로 국가별 관리한다.

### 決定事項

- 禁止keywordはcode定数ではなくGit追跡YAMLで国別管理する。
- 通常規則は`exact`を優先し、人名・政党の結合形だけ慎重に`contains`を使う。
- 不正な設定を無視せずbatchを失敗させ、既存の正常Pages結果を維持する。

### 問題とリスク

- 過度な`contains`規則は正常な経済keywordまで除外する可能性があるため、PR根拠とregression testが必要。
- global uv・pytest一時directoryのaccess制限はproject仮想環境とrepository内一時pathで回避検証した。
