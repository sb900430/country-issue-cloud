### 수행한 작업

- 실행 marker는 Ubuntu gate에서 확인하고 교차 OS cache로 공유하며, Windows build 전체 검증 후 외부 호출 직전에 저장하도록 변경했다. 기본 실행은 13시, 보충은 14시·16시로 옮겼다.
- 국가별 1개 이상 성공을 `partial_success`로 게시하고 실패 날짜·기사 수·사유를 `calendar.json`과 `status.json`으로 제공했다.
- live 실행도 기존 공개 `latest.json`을 복원해 당일 전 국가 실패가 마지막 정상 화면을 덮지 않도록 보완했다.
- Web이 최신 데이터를 먼저 표시하고 날짜·상태 metadata 실패를 격리하도록 바꿨으며 mutable JSON의 browser cache를 우회했다.
- 키워드를 품질 기준을 통과한 3~5개로 변경하고 일반어·언론사명·숫자·정치인 필터와 영어 활용형 보정을 추가했다.
- 매체명을 정규화하고 보도자료 wire 계열을 통합했으며 최종 선택 수에 수렴하는 20% 편중 제한을 적용했다.
- local embedding의 기사 제목 응집도를 순위에 반영하고 중심 기사를 관련 기사 앞에 배치했다.
- 비공개로 저장된 8월 17~19일 관리자 표본을 외부 API 호출 없이 재분석했다. 무의미한 후보만 남은 미국 날짜는 미국만 실패하고 일본·한국 결과는 유지되는 것을 확인했다.
- Schema 2.0에 하위 호환 `label_ko`를 추가하고 순위 완료 후 무료·version 관리 번역 사전을 적용했다. 미등록 표현은 원문으로 fallback한다.
- Web에 기본 한국어 `원문 / 한국어` segment를 추가해 타일·cloud·상세 title을 로컬 전환하고 관련 기사 title은 원문으로 유지했다.
- 미국·일본·한국 fixture, 이전 JSON 호환, 잘못된 번역 field 거부와 로컬 Pages 실제 클릭 흐름을 검증했다.
