PROJECT POLICY

출처와 이용 안내
出典と利用案内

데이터 출처 · データ出典

미국·일본·한국 공공기관의 공식 RSS·Atom과 허용된 공개 API만 사용합니다. 각 이슈의 링크는 제공기관 원문으로 연결됩니다。

수집 범위 · 収集範囲

제목, 기관명, 발행 시각, 원문 URL 등 허용된 최소 정보만 처리합니다. 기사 본문, 첨부파일, 이미지와 개인정보는 수집하거나 재배포하지 않습니다。

보관 · 保存

공개 결과는 최근 7일만 유지합니다. 브라우저는 장애 복구를 위해 마지막 정상 공개 결과를 로컬에 임시 저장할 수 있습니다。

면책 · 免責

이 사이트는 비상업적 개인 포트폴리오이며 공식 기관 서비스가 아닙니다. 자동 분류 결과는 원문을 대신하지 않으므로 중요한 판단은 연결된 원문에서 확인하세요。

개인정보 · 個人情報

회원가입, 쿠키 기반 광고, 사용자 추적 도구를 사용하지 않습니다. GitHub Pages 운영 과정의 기술 로그에는 GitHub 정책이 적용됩니다。

문의 · お問い合わせ

오류, 삭제 요청과 출처 관련 문의는 GitHub Issues를 이용해 주세요. API key나 개인정보는 게시하지 마세요。
