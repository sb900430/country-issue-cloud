# Contributing

1. Read `AGENTS.md` and both project specifications.
2. Work on the milestone branch defined in the specifications.
3. Keep method-level comments and explanatory TODO/FIXME text in Japanese.
4. Run `scripts/verify-all.ps1` before committing.
5. Use the required dated English/Korean/Japanese commit subject.
6. Open a Draft PR and merge with Rebase and merge only after verification passes.
